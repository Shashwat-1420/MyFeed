Guidance for AI agents (and humans) working in this repo. Read this before changing code.

## 1. What this project is

A "save-it-now, resurface-it-later" read-later / second-brain app: share a link from
Instagram / YouTube / Reddit / X, it gets scraped, AI-categorized, and then resurfaced on a
spaced-repetition schedule so you actually retain what you save.

It is an entry for the **iQOO hackathon** (Reskilll platform), with two deadlines that drive
all sequencing:

| Date | Event | Notes |
|---|---|---|
| **2026-09-22** | Reskilll platform submission | Web app (Phase A) pushed ✅ |
| **2026-09-26/27** | Hyderabad City Battle demo | Loaner iQOO phone handed at check-in — sideload dev APK there |
| **2026-10-09/11** | Finale (per original plan) | |

The iQOO judging rubric: **End product 30% · Novelty 20% · Creative phone use 15% ·
Technical depth 15% · Office Kit 10% · Demo 10%**. It explicitly rewards **a local or
open-source model at the core** and **on-device / NPU usage**.

**Implication: on-device local AI categorization is the single highest-value feature for scoring.**

## 2. Current state of the repo

- **Stack:** **Expo SDK 57 + React Native 0.86 + React 19.2 + NativeWind 4 + Zustand**.
  The old Vite web app has been **replaced** (Phase B). It still exists in git history at
  commit `b9af2cf` if the web build is ever needed again.
- **Entry:** `index.ts` → `src/App.tsx`. Views in `src/views/`, components in
  `src/components/{common,navigation,saves}/`.
- **State:** `src/store/useSavedFeedStore.ts` (Zustand) is the single source of truth.
  Store-driven navigation — **no router**; `currentTab` + `currentScreen` decide what renders.
- **Styling:** NativeWind (Tailwind classes on RN). Semantic tokens only — see §5.
- **Native config:** `app.json` drives `expo prebuild` (CNG). `android/` and `ios/` are
  **generated, gitignored, never committed**.
- **Backend:** `supabase/` holds `schema.sql` and an edge function `process-save`. It is
  optional/legacy — on-device AI is the primary path and `aiAdapter.ts` keeps a keyword fallback.

### Commands
```bash
npm install                    # install deps
npx tsc --noEmit               # typecheck — primary gate (currently 0 errors)
npx expo export -p android     # bundle gate — catches NativeWind/babel/Metro errors
npx expo start                 # dev server (QR / dev-client)
npx expo run:android --device  # build + install on a USB phone (auto-prebuilds)
npx expo prebuild -p android --clean   # regenerate android/ from app.json
npm run lint                   # BROKEN — eslint not installed, no config. Not a regression signal.
```
`npm run build` (Vite) **no longer exists** — it was removed with the web app.

### Known repo quirks
- `npm run lint` is broken. Don't "fix" it by installing eslint unless asked.
- `android/`/`ios/` are regenerated by prebuild; edit `app.json` (or config plugins), not the
  generated native files.
- `savedfeed_final_implementation_plan.md`, `savedfeed_design_report_antigravity.md`, and
  `savedfeed_project_context (1).md` are **planning docs, not truth** — trust the source.

## 3. The agreed roadmap (Phases A → B → C)

### Phase A — pre-submission web fixes — ✅ DONE (2026-09-22, commit `b9af2cf`)

Fixed dark mode by moving chrome to **CSS-variable-backed semantic Tailwind tokens**
(`bg-canvas`/`bg-panel`/`bg-chip`/`text-ink`/`text-muted`/`text-dim`/`border-edge`/`text-gold`),
swept the leftover indigo palette to iQOO yellow, fixed white-on-gold contrast, added the
missing `fadeIn`/`bounceIn` keyframes, and documented the roadmap here. Verified: `tsc` → 0,
`vite build` → 0.

### Phase B — Expo conversion — ✅ DONE (2026-09-22)

The Vite app was replaced by an Expo/RN app **in the same repo**:

- **Expo SDK 57** (not the 54/55 in the old plan — SDK 57 is current and `expo-share-intent@8`
  requires `expo ^57`). RN 0.86.3, React 19.2.3.
- **NativeWind 4** set up: `babel.config.js` (`jsxImportSource: nativewind` + `nativewind/babel`),
  `metro.config.js` (`withNativeWind(config, { input: './global.css' })`),
  `tailwind.config.js` (`presets: [require('nativewind/preset')]`), `global.css`,
  `nativewind-env.d.ts`.
- **Theme ported via `vars()`** (`src/lib/theme.ts`) instead of `:root` CSS, applied on the root
  `<View>` in `App.tsx` from the store's `darkMode`. `useThemeColors()` exposes resolved hexes for
  places className can't reach (react-native-svg icon `color`/`fill` props).
- **Brand yellow is now `#FFC800`** (was `#F0B31C`), on near-black `#08080C`. Light-mode gold
  text darkens to `#8A6A00` for contrast.
- **All 9 views + 9 components ported**: `div→View`, text tags→`Text`, `button→Pressable`,
  `input/textarea→TextInput`, `img→Image`, `lucide-react→lucide-react-native`.
  `MobileFrame` was dropped (web-only chrome).
- **Porting decisions for web-only features:**
  - `canvas-confetti` → no-op shim `src/lib/confetti.ts` (`celebrate()`) — see Phase C polish.
  - CSS gradients (`bg-gradient-to-*`) → flat translucent scrims/tints.
  - `@keyframes` animations, `backdrop-blur`, `hover:`/`group-hover:` → dropped (no RN equivalent).
  - `space-x-*`/`divide-*`/`grid-cols-*` → `gap-*`, explicit borders, `flex-wrap`.
  - `overflow-*` → `ScrollView`; `fixed` → absolute overlay / RN `Modal` (BottomSheetModal).
  - `<select>` → inline chip picker.
  - Profile JSON export: Blob/`<a download>` → RN `Share` sheet.
  - `window.open`/`<a href>` → `Linking.openURL`.
  - `document.*` in the store → removed (theme is applied by the root View).
  - `import.meta.env` → `process.env.EXPO_PUBLIC_*`; `new URL()` → regex host parse (Hermes-safe).
- **Verified:** `npx tsc --noEmit` → 0 errors; `npx expo export -p android` → bundled (3031 modules);
  `npx expo prebuild -p android` → succeeded and applied the share-intent filters.

## 5. House rules for agents

- **Scope:** do exactly what was asked (a phase, a fix). Don't refactor unrelated code.
- **Match surrounding style.** Store-driven, mock-first, NativeWind-classed.
- **Verify before claiming done:** `npx tsc --noEmit` **and** `npx expo export -p android` must both
  pass. Do not rely on `npm run lint` (broken, see above).
- **Theme:** use the semantic tokens (`bg-canvas`/`bg-panel`/`bg-chip`/`text-ink`/`text-muted`/
  `text-dim`/`border-edge`/`text-gold`) for chrome, never raw hex. Raw hex is allowed only for:
  category colours (`src/lib/categories.ts`), status/danger colours, platform colours, brand yellow
  fills (`bg-gold-fill` + `text-black`), and the light-mode palette in `src/lib/theme.ts`.
- **Both themes matter.** Any new surface/text colour must work in dark *and* light — add values to
  both `DARK_VARS` and `LIGHT_VARS` in `src/lib/theme.ts` (and `THEME` for icon hexes).
- **Native constraints to remember:** no CSS gradients, no `backdrop-blur`, no `hover:`, no CSS
  `@keyframes`, no CSS grid, no `divide-*`/`space-x-*` (use `gap-*`), no `fixed` — see the Phase B
  list for the RN equivalents already in use.
- **Icons:** `lucide-react-native` — pass `size`/`color`/`fill` props, not `className` (SVG props
  aren't reached by Tailwind). Use `useThemeColors()` for the colour.
- **Planning docs are stale; source is truth.**
